# Продолжение разработки

Текущий этап: v0.0.15, первый графический билд. Приоритет пользователя —
интерфейс, который можно попробовать обычному пользователю. Полная исходная
цель ОС ещё не достигнута. Архитектура микроядра утверждена, расширение .nos
и свой формат ABI поверх ELF64 также утверждены.

Работают собственное ядро x86-64, ring-3 задачи, таймер, IPC с правами, отдельный
файловый сервис FS3, 128 файлов до 1 МиБ, транзакции и миграция старого диска.
Есть нативный C/ASM-компилятор TinyCC и SDK (21 файл), статическая библиотека C,
динамическая куча 2 МиБ. C++, самосборки и полной libc пока нет.

Supervisor файлового сервиса реализован: следующий новый запрос может поднять
сервис заново, старый запрос записи не повторяется. Три попытки за загрузку,
затем только restartfs. Проверены реальный сбой во время PIO, сброс контроллера,
откат транзакции, протокольные ошибки и освобождение памяти.

Графика: desktop.nos в user space, ограниченные display/input системные вызовы,
мышь PS/2, окна с перетаскиванием, Files/Notes/Calculator/Appearance. Инструменты
пока внутри одного процесса. Notes до 8 КиБ, Ctrl+S/Tab/стрелки; подтверждение
замены файла и потери буфера. Настройка цвета в desktop.cfg. Каталогов, Unicode,
буфера обмена, запуска .nos из проводника и общего процесса для каждого окна нет.
Описание и реальные проверки — desktop.md и validation.md.

Билд 0.0.15 собран, проверки завершены, рабочая VMware загружена с новым ISO.
Диск данных сохранён (побайтово тот же data-flat.vmdk). Версия исходников и настоящего
скриншота — main/v0.0.15. Теперь нужен первый пользовательский
просмотр и обратная связь об интерфейсе. Следующий ограниченный шаг по его
итогу: удобный текстовый ввод (Unicode/кириллица и редактирование) и запуск .nos
из рабочего стола через общий менеджер процессов, без выдачи программам display
и disk-port прав по умолчанию.

Публикация исходников разрешена пользователем 2026-11-03:
https://github.com/wion4/NeuroOS (public). Для своего кода выбрано «пока без
лицензии»: код виден, права на использование не выдаём. Не подменять это MIT/GPL.
Сторонние лицензии сохранены. Git identity — подтверждённый аккаунт wion4 и его
GitHub noreply, настройки только этого репозитория. Публичная раздача бинарного
ISO не выполнялась; локальный ISO предназначен для рабочей VM.

Не удалять/не перезаписывать vmware/data.vmdk и data-flat.vmdk, не трогать
физические диски. Перед миграциями — проверенная резервная копия. Тесты используют
только явно названные собственные образы. Реальная конфигурация VMware теперь
игнорируется Git; в репозитории обезличенный .vmx.template и setup-vm.py.
Не выкладывать авторизационные данные, журналы или диски виртуальной машины.

Общего менеджера процессов, локального инференса, истории диалогов и управления
агентами пока нет. Не объявлять весь проект завершённым после первого GUI.
