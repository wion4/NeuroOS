# Desktop 0.0.18

Рабочий стол — отдельная программа desktop.nos в ring 3. Встроенные окна
Files/Notes/Calculator/Appearance/Programs принадлежат одному desktop-процессу.
Нативная запущенная .nos и файловый сервис изолированы от него. Это ещё не общий
композитор и не многопроцессная оконная среда: на время foreground-программы
рабочий стол приостановлен, затем восстанавливается с тем же буфером заметок.

## Заметки и текст

- UTF-8, русский и английский ввод. Переключение RU/EN — кнопкой сверху или
  Alt+Shift. Русская раскладка JCUKEN; Shift/CapsLock, Ё/ё, знаки пунктуации.
- Собственные bitmap-глифы ASCII и русского алфавита. Другие корректные Unicode
  scalar values сохраняются, но неподдерживаемый глиф показан рамкой. Нет shaping,
  bidi или навигации по grapheme clusters: курсор движется по кодовым точкам.
- До 8192 байт документа, имена до 15 ASCII-символов. Большие документы и бинарные/
  повреждённые UTF-8 файлы отклоняются без замены открытого буфера. CRLF читается
  и сохраняется; CR не рисуется. Ограничение имени не является пределом языка текста.
- Ctrl+S — сохранение, Ctrl+L — поле имени, Enter/Tab из поля имени — текст.
  Tab в тексте вставляет четыре пробела. Стрелки, Home/End, Ctrl+Home/End,
  PageUp/PageDown, Delete и Backspace сохраняют границы UTF-8.
- Shift+навигация и перетаскивание мышью выделяют. Ctrl+A выделяет всё;
  Ctrl+C/X/V используют внутренний буфер Notes (не буфер Windows).
- Ctrl+Z/Y и Ctrl+Shift+Z: undo/redo последних восьми изменений, без записи на
  диск. Откат к сохранённому содержимому снимает флаг Unsaved. История и clipboard
  исчезают при закрытии desktop-процесса. Закрытие окна только скрывает инструмент.
- Кнопка + в заголовке разворачивает Notes, кнопка - возвращает прежний размер.
- Замена другого существующего файла и потеря несохранённого буфера требуют
  подтверждения в самой гостевой ОС. Сохранение использует FS_BEGIN/COMMIT.

UTF-8 decoder проверяет минимальную форму, продолжения, суррогаты и верхнюю
границу U+10FFFF. Контрольные символы (кроме CR/LF/Tab) в текст не принимаются.
Невместившаяся вставка сохраняет весь текущий документ. Файл не меняется до Save.
См. [RFC 3629](https://www.rfc-editor.org/rfc/rfc3629.html).

## Файлы, программы и C

Files показывает реальный диск, страницы Prev/Next, Refresh, New note.
Open / Run открывает текст или выбирает .nos в Programs. Имя и аргументы можно
также вписать в Programs; Run/Enter запускает программу. Галочка Allow file access
по умолчанию выключена и сбрасывается при изменении имени программы. Она выдаёт доступ ко всему текущему файловому сервису,
а не к одному выбранному файлу; per-file grants пока нет.

Build C для выбранного .c (имя до 13 символов) выбирает compiler.nos и аргументы
SOURCE.c SOURCE.nos. Пользователь проверяет аргументы и отдельно включает файловые
права компилятора перед Run. Результат появляется в Files. Ошибки компиляции не
заменяют предыдущий корректный output; это свойство проверенного нативного порта.
В desktop-bootstrap, вместе с первоначальным SDK при отсутствии соответствующих
имён, устанавливаются hello.nos и compiler.nos. Пользовательские одноимённые файлы
не заменяются. Это не автоматическое выполнение найденных приложений.

Programs показывает stdout (до 2047 печатных ASCII-байтов), признак обрезки,
exit code либо причину остановки, Up/Down для просмотра. stdin у запускаемых
программ пока отсутствует. Один foreground-процесс за раз, прежний CPU-бюджет
1000 тиков; сбой/исчерпание бюджета не завершают desktop. Консольный сервис пока
остаётся в ядре, кнопка Console возвращает его; desktop открывает интерфейс снова.
Настройки Style сохраняются в desktop.cfg. Конфликт имени с посторонним файлом
отклоняется. Калькулятор — целые числа и одна операция; деление целочисленное.

## Привилегии и жизненный цикл

Display/input/launch доступны только фиксированному desktop boot-модулю.
Обычные run/runfs, включая дочерние GUI-запуски, никогда не получают этих прав.
Файловые права ребёнку выдаются только при флаге NOS_LAUNCH_FILES. ATA-порты
доступны только файловому сервису. Каждый .nos проверяется настоящим ELF-loader.

11/0 возвращает 32-байтовый desktop_input: координаты/кнопки, ASCII-совместимый
ключ, тики, модификаторы и физический scancode. RU/EN и UTF-8 преобразование — в
пользовательском пространстве. Диагностическая консоль сохраняет ASCII-режим.
11/1 принимает ровно 800x600 RGB32, kernel user_copy_from проверяет страницы и
учитывает pitch/каналы firmware. Framebuffer не отображён в пользовательскую память.
12 — ограниченный sleep доверенного desktop, не доступный обычным приложениям.
Задача просыпается по тику; другие задачи продолжают выполняться. При отсутствии
runnable задач CPU ждёт таймер через HLT.

13 принимает launch_request (100 байт) и проверенный writable launch_result
(2072 байта). SUSPENDED переводит desktop в сохранённое состояние с его страницами,
кучей и FXSAVE. В kernel-root проверяется/читается файл через отдельный файловый
процесс, запускается обычная задача, затем восстанавливается desktop. Сессии IPC
не переносятся ребёнку; очищаются незавершённые транзакции. Неуспешная запись не
повторяется. Завершившаяся программа освобождает свои страницы/кучу. Результат и
ограниченный вывод копируются в ранее проверенный буфер desktop.

PS/2: раздельный приём keyboard/трёхбайтовых mouse-пакетов, bounds/sign/overflow;
USB, колесо, ускорение, VSync и host clipboard не реализованы. Видеорежим 800x600x32;
при большем framebuffer холст центрируется, неподходящий режим возвращает консоль.

Проверки: tests/test_text.py, tests/test_desktop.py, tests/test_desktop_workflow.py.
Тесты работают на своих явно названных дисках, вводят реальные QMP/PS2-события,
проверяют UTF-8 байты и CRC независимым чтением диска, холодную загрузку, права,
сбой/CPU-лимит, native C build/run и счётчик физических страниц. Мышь Windows
не используется. Запуск в VMware проверяется отдельно по свежему serial.

## Дополнение 0.0.18

В optional AI-сборке верхняя AI demo открывает интерфейс отдельного offline CPU
runtime. Generate, англоязычный prefix, Up/Down, Cancel и Unload. Генерация фоновая:
Notes и файловые операции продолжают работать; Ctrl+Alt+G запускает текущий
prompt без перехода в AI окно. Сбой/отмена сохраняет состояние заметок.
Esc в окне AI отменяет генерацию. Ctrl+Alt+Q возвращает в Console с тем же
подтверждением несохранённых изменений, что у кнопки Console.
Это учебный генератор английских историй.
Протокол и ограничения — [ai-demo.md](ai-demo.md).
